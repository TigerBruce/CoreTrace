# 使用 CoreTrace

[返回首页](../README.md) · [统计口径](METRICS.md)

## 第一次运行

解压完整便携包到可写入的文件夹，运行 `CoreTrace.exe`。无需安装应用；布局、主题等设置保存在同目录的 `settings.ini`，所以不要直接在压缩包里运行。

默认固定模式将窗口放在普通应用后面、桌面前面。它是独立窗口，并非写入桌面背景的图片。运行中的普通应用可以覆盖它。

CPU 总体卡片左上角的小铅笔用于打开编辑区。也可以用命令 `CoreTrace.exe --adjust` 启动编辑模式；已有实例运行时，先使用现有实例上的小铅笔。

## 移动和调整大小

| 要做的事 | 操作 |
| --- | --- |
| 移动整个窗口 | 编辑模式拖动上方系统标题栏或底部菜单空白处 |
| 调整整体长宽 | 拖动窗口四边或四角 |
| 调整 CPU 总体与内存高度 | 拖动 CPU 总体卡片下方的短横线；两张卡片一起变化 |
| 调整内存前五高度 | 拖动该卡片上方的短横线 |
| 调整下面核心图表 | 核心卡片自动分配剩余空间，随宽度换列 |
| 保存并收起工具 | 点击底部「固定」 |

没有滚动条。窗口最小高度随核心数、宽度和字号变化；空间不足时先扩大窗口，再调整单个区域。固定与编辑切换保留图表区域的尺寸和位置。

## 主题、透明度与字体

- 「主题」切换深色和浅色。
- 「外框透明」调整窗口背景与卡片边线；「卡片透明」只调整卡片底色。文字与曲线不随之变淡。
- 透明度范围为 0–80%，0% 表示完全不透明。编辑时系统标题栏和控制区仍可有不透明底色。
- 「字号」设置全局 12–22 号文字；内存排行还会随自身高度适配。
- 字体菜单提供等线、等线细体、微软雅黑 UI、微软雅黑 UI 细体、微软雅黑、黑体、宋体。缺失字体的系统可能使用 Windows 回退字体。

## 历史与统计模式

点击底部时间选项，在 20 秒、40 秒、1 分钟之间切换。暂停仅冻结可见历史，采样线程继续工作；恢复后显示最近数据。

「CPU 统计」菜单可选 Utility 或 Time，托盘菜单也提供同样选项。切换会重画已有历史，设置在退出后保留。

蓝色面积是负载，彩色细线是温度。顶部横线为 100%，内部三条线为 75%、50%、25%；温度线以 0–100°C 对应同一高度范围。图表为了紧凑省略刻度文字。编辑模式悬停可以查看所指采样点及当时 CPU 前五。

## 隐藏、退出与迁移

托盘图标右键可编辑、固定、隐藏或退出。编辑区底部也有红色「退出」。退出会保存设置。

复制整个便携文件夹即可迁移应用；新电脑如需受支持的温度与频率读取，仍需另装 PawnIO。要恢复默认布局，退出后将 `settings.ini` 重命名备份，再启动。删除应用文件夹即可移除应用；这不会卸载单独安装的 PawnIO。

## 常见问题

**温度或频率是空的？**

先确认 CPU 是否为当前支持的 Intel 型号，再检查 PawnIO 是否已安装、`IntelMSR.bin` 是否在 EXE 同目录。支持范围包含 06_9E（含 i7-8750H），启动时需要允许 Windows 管理员授权。温度区域显示具体失败原因，`--diagnose` 的 JSON 包含 `status`、总体 Time/Utility 及每核两种负载值。获得启动授权后，即使温度不可用，占用率和内存监控仍可工作；空值不应解释为 0°C。

**CPU 百分比与任务管理器不一致？**

先确认选择 Utility，并让两边观察相同的稳定负载阶段。刷新窗口不同会造成差异；每个小图合并物理核心内的逻辑线程，也不能与任意逻辑处理器编号直接比较。详见 [指标说明](METRICS.md)。

**内存前五与任务管理器不一样？**

这里按同名进程合并私有工作集；Windows 的应用分组、所选内存列和共享页统计可能不同。

**窗口变大后 CoreTrace 自身内存增加？**

绘图使用按窗口像素尺寸分配的 32 位位图，透明合成还需要额外表面，因此大窗口会占用更多内存。观察是否在尺寸固定后持续增长，才有助于区分缓冲区大小与泄漏。项目尚未提供覆盖所有配置的长时间稳定性数据。

**启动时 Windows 给出未知发布者提示？**

当前自行构建和 CI 产物未做发布者代码签名。请核对仓库来源和构建记录；项目没有把未签名产物描述为已通过系统认证的软件。
